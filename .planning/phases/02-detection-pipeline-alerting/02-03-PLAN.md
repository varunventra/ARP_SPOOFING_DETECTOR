<!-- DET-05 event dict — the input to format_alert_panel (locked from CONTEXT.md) -->

DET-05 event dict shape:
```python
{
    'timestamp':    str,   # ISO 8601 string, e.g. "2026-05-09T14:23:01.123456"
    'attacker_mac': str,   # e.g. "bb:bb:bb:bb:bb:bb"
    'victim_ip':    str,   # e.g. "192.168.1.1"
    'original_mac': str,   # e.g. "aa:aa:aa:aa:aa:aa"
    'spoofed_mac':  str,   # same as attacker_mac per spec
    'attack_type':  str,   # always "ARP_SPOOFING"
}
```

rich.Panel constructor (rich >= 13.x, HIGH confidence):
```python
from rich.panel import Panel
from rich.text import Text

panel = Panel(
    renderable,          # Text or str
    title="[bold red]ARP SPOOFING[/]",
    border_style="red",
)
# panel.border_style == "red"
# panel.title contains "ARP SPOOFING"
```

CRITICAL: format_alert_panel() ONLY builds and returns the Panel.
It does NOT call Console().print() or live.console.print().
The caller (main.py) is responsible for printing inside the Live context.
Calling Console().print() here would corrupt the Live display.
